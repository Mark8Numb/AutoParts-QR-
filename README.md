🚗 AutoQR — PWA для автодеталей + голосовые заметки

AutoQR — это прогрессивное веб-приложение (PWA), которое работает на телефоне и компьютере.
Оно помогает механикам и водителям:

· сканировать QR‑код автомобильной детали и сразу получать информацию о ней (совместимость, артикул, наличие);
· создавать голосовые заметки — речь автоматически превращается в текст;
· управлять заметками: удалять, скрывать, отмечать выполненные, сортировать;
· вести «Журнал водителя» — полный архив всех заметок и истории поисков;
· экспортировать все данные в JSON‑файл;
· работать оффлайн после первого открытия.

📦 Установка и запуск

1. Скачай файлы

Создай папку и помести в неё следующие файлы (все они перечислены в ответе ассистента):

· index.html
· app.js
· manifest.json
· sw.js
· icon.png (любое квадратное изображение 512×512)

2. Запусти локальный сервер (для работы камеры и Service Worker)

Вариант A (простой, через VS Code):

· Установи расширение Live Server
· Открой index.html → правой кнопкой → Open with Live Server

Вариант B (через Node.js):

```bash
npx http-server -p 8080
```

Затем открой в браузере http://localhost:8080

Вариант C (на телефоне):

· Загрузи файлы на любой HTTPS‑хостинг (или используй ngrok для локального сервера), так как камера и Service Worker требуют безопасного контекста.

3. Установи как PWA (на телефон)

· Открой сайт в Chrome / Safari на телефоне
· Нажми «Поделиться» → «На экран «Домой»» → «Установить»
· Теперь приложение запускается как отдельное, без адресной строки

🧠 Как пользоваться

Главный экран

1. Сканировать QR – нажми кнопку, разреши доступ к камере, наведи на QR‑код автодетали. Появится карточка с информацией.
2. Демо‑деталь – показывает случайную деталь из встроенной базы (для теста).
3. Записать голосовую заметку – нажми красную кнопку с микрофоном, продиктуй текст. Он появится в списке заметок.
4. Управление заметками:
   · ○ / ✓ – отметить выполненной
   · Поле «Слово для удаления» + кнопка – удалить все заметки, содержащие это слово
   · «Полный сброс» – удалить ВСЁ (заметки + историю поисков)

Журнал водителя

· Нажми «📓 Журнал Водителя» (в правом верхнем углу блока заметок)
· Ты увидишь все заметки (включая скрытые), а также историю поисков по QR
· Сортировка: выбери вариант в выпадающем списке – порядок сохранится
· Для каждой заметки:
  · Отметить выполненной
  · Скрыть / показать
  · Удалить
· Кнопка «Экспорт в файл» – сохранит текущее состояние (заметки, историю, настройки) в JSON
· Кнопка «Очистить историю» – удаляет только историю поисков, заметки остаются

---

⚙️ Данные и настройки

Все данные хранятся в localStorage браузера:

· autoqr_notes – массив заметок (текст, статус, скрыто, дата)
· autoqr_history – история поисков по QR
· autoqr_settings – выбранная сортировка

При экспорте создаётся JSON‑файл, который можно импортировать обратно (функцию импорта при желании легко добавить).

🛠️ Расширение базы автодеталей

Сейчас используется моковая база в файле app.js:

```javascript
const partsDatabase = {
  "BRAKE-PAD-FRONT": { name: "...", compatible: "...", sku: "...", stock: "..." },
  ...
};
```

Чтобы подключить реальное API, замени функцию showPartInfo(qrCodeData) – сделай fetch к своему серверу.

---

🧪 Требования к браузеру

· Камера – BarcodeDetector API (Chrome, Edge, Opera; Safari пока не поддерживает – использует fallback с ручным вводом)
· Голосовой ввод – SpeechRecognition (поддерживается в Chrome, Edge, Safari; в Firefox – нет)
· PWA (оффлайн) – любая современная версия Chrome / Safari на телефоне
